# Calisthenics Coach

A bodyweight training coach that runs in the browser and installs to your home screen. Built for the floor, a low table and a wall (a pull-up bar is optional).

- Every training day is a sheet of 6 exercises in complementary pairs (or a circuit for fat loss)
- Tap any exercise for start and finish pictures, step-by-step form, common mistakes and a demo link
- Progression ladders (e.g. incline → knee → push-up → diamond → decline → pseudo planche): hit the top of the rep range on every set and you level up automatically
- Goals: build muscle, get stronger, lose fat, general fitness; focus areas; joints to go easy on
- Logs every set, shows history and bests, rest timer, works offline; data stays on your device (Setup → Download backup)

## Install on your phone
1. Open the site in Safari (iPhone) or Chrome (Android).
2. iPhone: Share → Add to Home Screen. Android: ⋮ → Install app.
